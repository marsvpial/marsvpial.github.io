# COMO EDITAR OS TEXTOS DO SITE

Este guia explica como alterar todos os textos do seu site de forma simples, sem precisar mexer no código.

## IMPORTANTE
- Todos os textos do site estão na pasta `ur_Info`
- Cada arquivo `.txt` contém um texto específico do site
- Para alterar um texto, abra o arquivo correspondente e edite o conteúdo
- Salve o arquivo após fazer as alterações
- Atualize a página no navegador para ver as mudanças

## ⚠️ DICAS IMPORTANTES

1. **NÃO APAGUE** os arquivos `.txt`, apenas edite o conteúdo
2. **NÃO MUDE** os nomes dos arquivos
3. Use apenas texto simples (sem formatação especial)
4. Após editar, sempre **salve o arquivo**
5. **Recarregue a página** no navegador para ver as mudanças
6. Mantenha textos curtos para melhor visual do site

## 🚀 EXEMPLOS DE COMO EDITAR

**Para mudar o nome principal:**
1. Abra `aboutme_nome.txt`
2. Mude de "Olá! Eu sou a Carol" para "Olá! Eu sou a Maria"
3. Salve o arquivo
4. Recarregue a página aboutme.html

**Para mudar um emoji de habilidade:**
1. Abra `skill1_emoji.txt`
2. Mude de "🎨" para o emoji que desejar (ex: "✏️")
3. Salve o arquivo
4. Recarregue a página aboutme.html
